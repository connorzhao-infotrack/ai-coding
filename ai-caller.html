🗺️ Architecture (one picture)

🎯 1 · What it is

🧩 Service shape

  • Generic — not SettleIT-specific. Consumers pass opaque playbook + customFields.
  • REST trigger + webhook callback. SignalR for the internal dashboard only.
  • Playbooks are config, not code — adding councils is <1 day each.

📟 IVR-only · ~$0.10–0.25/call

  • Sydney Water
  • STT + text LLM + send_dtmf tool
  • Cheap and fast

🗣️ Human-agent · ~$0.40–1.00/call

  • Blacktown + Newcastle
  • Realtime voice (Gemini / OpenAI realtime — trial both)
  • Mock-up proves the pattern

It's the shared test harness, not just a demo tool: browser mic → SignalR → the same IVoiceAIService a real call uses, telephony bypassed.

  • Lets Ivy drive an end-to-end call from the trigger API

🏃 Fast-pace rules

  • Stub, don't wait. Fake a collaborator's piece against the agreed contract, swap later.
  • Lock the two service interfaces early — ICallProvider, IVoiceAIService — so voice + telephony build in parallel.
  • PR review < 2h. Block your own coding to unblock a teammate.
  • Auto-deploy on merge to main → stage. Prod from a release tag with an approval gate.
  • 1 hour stuck = pull someone in.

👀 9 · What a project lead should watch

📈 Metrics from day 1

  • Extraction quality — % calls with all required fields correct (spot-check)
  • Cost per successful call vs target band
  • Provider error rate — telephony 4xx/5xx, AI tool-call failures
  • Time-to-stage per change — the velocity signal that matters most this week

🧨 Top risks

  • Liability on wrong figures. Client pays based on what we extract — recording playback is the safety net. Don't ship to prod without it.
  • Day 1 contract day overruns. If interfaces aren't merged by Mon EOD, the whole week slips.
  • Low real-order volume. Newcastle especially — wait for June's volume data before authoring content. Make adding more council playbooks frictionless from day 1.
  • First-real-call surprises. Audio quality, IVR drift, regional accents. Bake in W2 buffer.
  • AI Gateway constraints. Find out from Chen Ni what's gated through the gateway before assuming direct API access. Realtime voice is exempt; text LLM isn't.
  • Vendor leak. Keep ICallProvider + IVoiceAIService abstractions clean.
